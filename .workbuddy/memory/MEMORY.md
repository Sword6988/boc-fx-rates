# rate 项目长期备忘

## 外汇牌价桌面程序（boc_fx_rates）
- 代码结构（2026-08-26 拆分）：`boc_fx_rates.py`（入口）→ `app.py`（界面）→ `fetcher.py`（抓取/解析/缓存）；成品 `dist/外汇现汇买入价查询.exe`
- 重打包：项目根目录运行 `.\build.ps1`（PyInstaller onefile + 图标 + 自动清理中间产物）
- 数据源：中行 https://www.boc.cn/sourcedb/whpj/（现汇买入价，每 100 外币兑人民币，页面 UTF-8）；秘鲁新索尔(PEN) 备用源：open.er-api.com/v6/latest/PEN（字段 rates 与 conversion_rates 需兼容）→ cdn.jsdelivr.net currency-api（`pen` → `cny`）
- 备用源注意：jsdelivr 不加版本号可用（`@fawazahmed0/currency-api/v1/currencies/pen.json`）；`@latest` 超时、`@1`/具体版本 404，勿改回
- 运行环境注意：本机托管 Python 无 tkinter；GUI 开发/打包一律用系统 Python 3.13 与项目 venv `.venv`
- 测试：离线解析/缓存测试 `python tests/test_parse.py`（fixture：`tests/fixtures/boc_whpj.html`）；联网抓取测试 `python _test_fetch.py`（量级 USD≈5-9，RUB≈0.03-0.3，PEN≈1-3）
- 2026-08-26 优化：默认每 10 分钟自动刷新（界面可勾选关闭）；中行牌价与秘鲁备用源并行抓取；证书降级仅限证书校验失败（15s 超时 + 瞬时错误重试 1 次）；currency-api 用 @1 锁主版本；刷新失败保留上次成功数据；`--debug` 写调试日志（目录不可写回退 `%TEMP%`）
- 2026-08-26 追加：HTML 解析改用 `html.parser.HTMLParser`，货币名称/现汇买入价两列均按表头动态定位；离线缓存 `fx_rates_cache.json`（exe/源码目录旁，启动先显示缓存再后台刷新）；JSON 解码用 `utf-8-sig` 防 BOM；状态栏自动换行
- 2026-08-26 UI 优化：刷新中按钮显示「刷新中…」；复制后按钮短暂显示「已复制 ✓」，双击卡片任意位置也可复制；右键菜单（复制数值/复制每100外币/立即刷新）；状态栏拆分（主状态 + 更新时间/下次自动更新独立一行）；数值用 Consolas 等宽字体（宽度 7，紧贴「人民币」）；时间格式统一为短格式；标签带 ●/◷ 符号；窗口启动居中
