# 2026-08-26

## 外汇现汇买入价桌面查询程序
- 交付物：`dist/外汇现汇买入价查询.exe`（PyInstaller onefile，约 12MB，双击即用）+ 源码 `boc_fx_rates.py`（纯标准库，无第三方依赖）
- 功能：抓取中行官网牌价页「现汇买入价」（美元、卢布），÷100 换算为 1 外币兑人民币显示；秘鲁新索尔中行无牌价，自动走备用源（open.er-api.com → currency-api@jsdelivr，市场参考价）并在界面标注来源差异
- 关键经验：
  - 托管 Python（.workbuddy/binaries）不带 tkinter，GUI 程序须用系统 Python 3.13（C:\Users\Administrator\AppData\Local\Programs\Python\Python313，含 tkinter 8.6）
  - 打包用项目 venv `.venv`（基于系统 Python）+ pyinstaller 6.22.2，命令见 MEMORY.md
  - open.er-api.com 响应字段已由 conversion_rates 改为 rates，解析须两者兼容
  - 中行牌价页为 UTF-8；「现汇买入价」取值按表头索引定位，不写死列号

## 程序优化（当日追加）
- 自动刷新：默认每 10 分钟，状态栏显示「下次自动更新 HH:MM」，界面可勾选关闭
- 并行抓取：中行牌价与秘鲁备用源用 ThreadPoolExecutor 并行，缩短刷新等待
- 网络层：证书降级仅限 `SSLCertVerificationError`（不再把超时/DNS 当证书问题）；15s 超时 + 瞬时错误重试 1 次；currency-api 改 `@1` 锁主版本
- 体验：刷新失败保留上次成功数值并标注「上次数据」；`_copy` 名称映射预计算；DPI 改 Per-Monitor V2
- 代码：`CURRENCIES` 改 namedtuple；表格单次解析；解码优先读响应头 charset；异常链 `raise ... from e`；`--debug` 文件日志
- 测试：`_test_fetch.py` 路径改为相对定位，断网时友好退出而非 KeyError

## 程序优化（第二轮）
- 代码拆分：`boc_fx_rates.py`（入口）→ `app.py`（界面）→ `fetcher.py`（抓取/解析/缓存），解析逻辑可脱离 tkinter 单测
- 解析：弃用正则，改用 `html.parser.HTMLParser` 结构化提取表格；货币名称与现汇买入价两列均按表头定位，表头缺失时告警并回退默认列序
- 离线缓存：`fx_rates_cache.json` 存上次成功数据（exe/源码目录旁），启动先显示缓存（标注「缓存数据」）再后台刷新；断网也能看到最近一次牌价
- 测试拆分：`tests/test_parse.py` 离线解析 fixture + 缓存读写（不联网）；`_test_fetch.py` 保留联网量级校验
- 打包：新增 `build.ps1` 一键打包并清理中间产物（纯 ASCII 编写，避免 PowerShell 5.1 按 ANSI 误读中文）
- 细节：`--debug` 日志目录不可写时回退 `%TEMP%`；JSON 解码 `utf-8-sig` 防 BOM；状态栏 `wraplength` 自动换行
